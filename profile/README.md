## ❓ FAQ

### Do I need to run it as Administrator?
No. This repository is an informational reference and does not include an executable or overlay.

### Does this repository include a script executable?
No. It covers scripting terminology, gameplay mechanics, and permitted companion-tool alternatives.

### Does it work on Windows 11?
Yes. The reference can be viewed on Windows 11 using a standard web browser.

### What League of Legends scripting features are covered?
Topics include champion combos, orbwalking, last-hit assistance, skillshot analysis, target selection, and objective tracking. These describe automation categories, not working features supplied by this repository.

### Can gameplay automation be used with Vanguard?
Riot identifies scripting and botting that take actions on a player's behalf as prohibited third-party behavior. Such tools can result in account suspensions, including permanent suspensions for repeated or blatant violations.
